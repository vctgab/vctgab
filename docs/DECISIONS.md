# Decisões

Registro de decisões do projeto. Cada linha diz o que foi decidido e por quê. Decisões tomadas sem consulta, conforme o briefing ("decida e registre").

## Ambiente (etapa 0)

| ID    | Decisão                                                                                                                                                          | Motivo                                                                                                                                                                                                                |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-001 | Node fixado em `24.21.0` no `.nvmrc`; `engines.node >=24.11.0`.                                                                                                  | É a versão LTS instalada e verificada nesta máquina. Em novembro de 2026 o Node 26 já entrou em LTS ativo; a migração fica nos próximos passos, porque não havia gerenciador de versões instalado para testá-lo aqui. |
| D-002 | pnpm 12.18.0 via Corepack, declarado em `packageManager`.                                                                                                        | Pedido do briefing; Corepack garante a mesma versão para quem clonar.                                                                                                                                                 |
| D-003 | Next.js 16.4.6 (estável mais recente), mantendo `cacheComponents`, `partialPrefetching` e o loader `@tailwindcss/turbopack` gerados pelo create-next-app.        | É a configuração recomendada pela própria versão; Cache Components mantém a vitrine pré-renderizada. Consequência: nada aleatório ou dependente de relógio no render do servidor.                                     |
| D-004 | `typedRoutes: true`.                                                                                                                                             | Links internos verificados pelo TypeScript.                                                                                                                                                                           |
| D-005 | `app/` movido para `src/app`, alias `@/*` aponta para `src/*`.                                                                                                   | Pedido do briefing.                                                                                                                                                                                                   |
| D-006 | TypeScript estrito com `noUncheckedIndexedAccess`, `noImplicitOverride`, `allowImportingTsExtensions`.                                                           | `allowImportingTsExtensions` permite que os scripts rodem direto no Node 24 (remoção de tipos nativa) importando módulos de `src/lib` sem `tsx`.                                                                      |
| D-007 | `reference/` fora do git.                                                                                                                                        | O HTML exportado do protótipo tem 880 KB de fontes embutidas e nomes de clientes; o repositório pode ser público.                                                                                                     |
| D-008 | `.gitattributes` com `eol=lf`.                                                                                                                                   | A máquina usa `core.autocrlf=true`; o Prettier exige LF.                                                                                                                                                              |
| D-009 | Regras de ESLint próprias: `Math.random` proibido (FM-01 do motor), `toLocale*String` e `new Intl.*` proibidos fora de `src/lib/format` (NU-12), `any` proibido. | Torna regras do briefing verificáveis pelo lint, sem opinião.                                                                                                                                                         |

## Dependências

| Pacote                                                                                                       | Tipo    | Por que existe                                                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------ | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `next`, `react`, `react-dom`                                                                                 | runtime | Framework pedido.                                                                                                                                                     |
| `radix-ui`                                                                                                   | runtime | Comportamento e acessibilidade de Dialog, Tabs, ToggleGroup, Switch, Checkbox, RadioGroup, Select, Tooltip, Popover, Toast, Accordion e Slot. Nenhum estilo vem dele. |
| `clsx`                                                                                                       | runtime | Composição condicional de classes.                                                                                                                                    |
| `tailwind-merge`                                                                                             | runtime | Resolver conflitos de utilitários quando o consumidor passa `className`.                                                                                              |
| `class-variance-authority`                                                                                   | runtime | Variantes tipadas (`*.variants.ts`).                                                                                                                                  |
| `tailwindcss`, `@tailwindcss/turbopack`                                                                      | dev     | Tailwind v4 CSS-first; o loader do Turbopack substitui o PostCSS nesta versão do Next.                                                                                |
| `typescript`, `@types/*`                                                                                     | dev     | Tipagem estrita. `@types/node` na linha 24, igual ao runtime.                                                                                                         |
| `eslint`, `eslint-config-next`                                                                               | dev     | Lint padrão do Next.                                                                                                                                                  |
| `eslint-plugin-jsx-a11y`                                                                                     | dev     | Importado só para ler o conjunto `recommended` e elevá-lo a erro (o plugin já vem registrado pelo `eslint-config-next`).                                              |
| `prettier`, `prettier-plugin-tailwindcss`                                                                    | dev     | Formatação e ordenação estável de classes.                                                                                                                            |
| `vitest`, `@vitejs/plugin-react`, `jsdom`                                                                    | dev     | Testes de unidade e componentes.                                                                                                                                      |
| `@testing-library/react`, `@testing-library/dom`, `@testing-library/user-event`, `@testing-library/jest-dom` | dev     | Testes de renderização e interação pelo ponto de vista de quem usa.                                                                                                   |
| `jest-axe`, `@types/jest-axe`                                                                                | dev     | Verificação axe em cada componente.                                                                                                                                   |
| `@playwright/test`, `@axe-core/playwright`                                                                   | dev     | E2E da `/sistema` nos 4 temas, axe no navegador real e capturas.                                                                                                      |

Sem biblioteca de animação: tudo em CSS e, no hero, `requestAnimationFrame` limitado a 30 fps.
