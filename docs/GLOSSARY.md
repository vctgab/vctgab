# Glossário

Um termo por conceito (regra VC-01). Se um texto precisar de um conceito que não está aqui, acrescente a linha antes de usar.

| Termo              | Definição                                                                                             | Nunca usar                                                |
| ------------------ | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| achado             | Cada um dos sete encontráveis escondidos pelo site. Plural "achados". O contador é "Achados: 3 de 7". | item, coleção, conquista, troféu, segredo (para o objeto) |
| caderno de achados | O painel que lista os sete achados, com dicas e progresso.                                            | inventário, coleção                                       |
| dica               | Frase curta, em Caveat, que orienta onde procurar um achado. Camada de mistério.                      | pista (como sinônimo), hint                               |
| página secreta     | Página liberada ao chegar a 7 de 7.                                                                   | área VIP, bônus                                           |
| tema               | Combinação de estação (primavera, verão, outono, inverno) e modo (claro, escuro).                     | skin, visual                                              |
| estação            | Eixo do tema que define cores, cena do rodapé, paleta do hero e energia das formas.                   | stação, época, season                                     |
| modo               | Eixo do tema que define claro ou escuro; na primeira visita segue a preferência do aparelho.          | dark mode (em texto visível), skin                        |
| projeto            | Trabalho listado no portfólio.                                                                        | job, trabalho, portfólio (para um item)                   |
| caso               | Página longa que conta um projeto (ex.: "Ler o caso Nexuscoop").                                      | case, estudo de caso                                      |
| ficha              | Card de papel do sistema (componente `Ficha`).                                                        | card (em texto visível)                                   |
| terminal           | A janela `cmd` com linha de comando. Camada de mistério.                                              | console, shell (em texto visível)                         |
| vitrine            | A rota `/sistema`, que mostra o design system.                                                        | storybook, playground (exceto o playground de formas)     |
| mensagem           | O que alguém envia pelo contato.                                                                      | contato (como substantivo para a mensagem), lead          |
| orçamento          | Pedido de proposta de trabalho.                                                                       | cotação                                                   |
| vaga               | Oportunidade de emprego ou contratação de Victor (CTA "tenho uma vaga", aba "vaga" do contato).       | job, position, oportunidade (como rótulo)                 |
